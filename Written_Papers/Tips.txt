To write an academic paper using Markdown, do the followings:
	Install pandoc:
		Navigate to "https://github.com/jgm/pandoc/releases/tag/3.8.3"
		Click on "pandoc-3.8.3-windows-x86_64.msi"
		Install the installer
	Install LaTeX:
		Navigate to "https://miktex.org/download"
		Install the installer
		Update MiKTeX:
			Restart the PC
			Click on Search bar on your Desktop
			Type "console"
			Open "MiKTeX Console"
			Click Updates
			Click Check for updates
			Click Update now
	Install Typora:
		Navigate to "https://typora.io"
		Click on "Download" at top right of the webpage
		Install the installer
	Create a configuration file for your paper:
		Create a file "paper_template.tex"
		Open the file
		Paste the following in this file:
		\documentclass[10pt,twocolumn]{article}

		% -------------------- PAGE & FONT --------------------
		\usepackage[margin=0.75in]{geometry}
		\usepackage{times}
		\usepackage{microtype}

		% -------------------- MATH & SYMBOLS --------------------
		\usepackage{amsmath,amssymb}

		% -------------------- FIGURES & TABLES --------------------
		\usepackage{graphicx}
		\usepackage{booktabs}
		\usepackage{caption}
		\usepackage{subcaption}

		% -------------------- LINKS --------------------
		\usepackage[colorlinks=true,allcolors=blue]{hyperref}

		% -------------------- LIST COMPACTING --------------------
		\usepackage{enumitem}
		\setlist[itemize]{noitemsep,topsep=1pt,leftmargin=1.2em}

		% -------------------- SECTION FORMATTING (CLEAN CVPR STYLE) --------------------
		\usepackage{titlesec}

		\titleformat{\section}
  		  {\normalfont\bfseries\fontsize{11}{13}\selectfont}
                  {\thesection}{0.6em}{}

		\titleformat{\subsection}
  		  {\normalfont\bfseries\fontsize{10.5}{12}\selectfont}
  	 	  {\thesubsection}{0.6em}{}

		\titleformat{\subsubsection}
  	  	  {\normalfont\itshape\fontsize{10}{11}\selectfont}
  	          {\thesubsubsection}{0.6em}{}

		\titlespacing{\section}{0pt}{6pt}{4pt}
		\titlespacing{\subsection}{0pt}{5pt}{3pt}
		\titlespacing{\subsubsection}{0pt}{4pt}{2pt}

		% -------------------- PANDOC FIX --------------------
		\providecommand{\tightlist}{%
  	 	  \setlength{\itemsep}{0pt}\setlength{\parskip}{0pt}}

		% -------------------- ABSTRACT (FULL WIDTH, UNNUMBERED) --------------------
		\usepackage{abstract}
		\renewcommand{\abstractnamefont}{\normalfont\bfseries}
		\renewcommand{\abstracttextfont}{\normalfont\small}
		\setlength{\absleftindent}{0pt}
		\setlength{\absrightindent}{0pt}

		\usepackage{etoolbox}
		\patchcmd{\abstract}{\hrule}{\relax}{}{}

		% -------------------- TITLE FORMAT --------------------
		\usepackage{authblk}
		\title{\vspace{-1.2em}\Large\bfseries $title$ \vspace{-0.5em}}
		\author{\normalsize $author$}
		\date{}

		% IMPORTANT: LET PANDOC CONTROL ALL NUMBERING
		\setcounter{secnumdepth}{3}

		\begin{document}
		\maketitle

		% -------------------- ABSTRACT --------------------
		$if(abstract)$
		\begin{abstract}
		\noindent $abstract$
		\end{abstract}
		$endif$

		% -------------------- BODY --------------------
		$body$

		\end{document}        
	Create your paper file:
		Open Typora
		Click File → New
		Save as: my_paper.md
	Paste your paper content in this file:
		---
		title: "Your Paper Title"
		author: "Your Name"
		date: "2025"
		---

		# 1. Abstract
		Write your abstract here (150–250 words).

		# 2. Introduction
		Introduce your problem, motivation, and contributions.

		# 3. Related Work
		Summarize prior work and position your paper.

		# 4. Method
		Describe your technical approach with equations.

		## 4.1 Model Architecture
		Details here.

		## 4.2 Training Procedure
		Details here.

		# 5. Experiments
		Datasets, baselines, metrics.

		## 5.1 Dataset
		## 5.2 Evaluation Metrics
		## 5.3 Results

		# 6. Discussion
		Analysis and limitations.

		# 7. Conclusion
		Summary and future work.

		# References
	Navigate to your paper folder
	Hold shift and right click
	Click on "Open Power Shell window here"
	Run the following commands:
		pandoc "my_paper.md" `
		  --standalone `
  		  --template=paper_template.tex `
  		  --pdf-engine=xelatex `
  		  -o "my_paper.pdf"
